Philippine Bar Recitation Simulator · Universal Hybrid Engine

1 Gemini API Key Setup (Requires Personal @gmail.com)
⚠️ Account Restriction: Use a personal `@gmail.com` account. University and school email domains (e.g., `@sanbeda.edu.ph`) block Google Cloud Platform (GCP) key creation and will return a "permission denied" error.
  1. Click "Open Google AI Studio ↗", sign in with your personal Gmail, and accept terms.
  2. Click the white "Create API key" button → select "Create API key in new project".
  3. Copy the code (AIzaSy...) and paste it into the Gemini API Key box in Setup.
  4. Multi-Project Rotation: Create 2 or 3 keys in separate projects and paste them separated by commas to avoid hitting the 15 Requests Per Minute (RPM) free-tier limit during compilation.
2 How to Import Files into the Simulator (4 Pathways)

The simulator supports four distinct file import methods, each tailored to a specific study workflow:

A. Course Syllabus (.pdf, .txt, .md) Anchor 1

Click "Attach Course Syllabus" in Setup. The parser extracts numbered modules, statutory provisions, and Supreme Court case titles to construct your study outline.

B. Reference Sources & Digests (.pdf, .txt, or Directory) Anchor 2

Click "Attach Reference PDFs" or "Upload Folder" to batch-import case digests, codals, and reviewers. Matched case facts and rulings load in 0 ms locally. Note: Scanned photo PDFs must be Optical Character Recognition (OCR) processed so the simulator can extract readable text.

C. Pre-Compiled Flashcard Decks (.json) Zero API Key Needed

Under Saved Decks, click "+ Import Deck (.json)" to load a deck exported by a classmate. You can immediately drill all questions and model answers without needing an active API key.

D. Full Workspace Master Backup (.json) Full Migration

At the bottom of Setup, click "Import Backup (.json)" to restore your complete database (all subjects, decks, mastery progress, and uploaded reference sources) when switching laptops.

3 Anchors & Coverage Scope (Unlocking the Gatekeeper)

To prevent AI hallucinations, the launch button remains locked until you set up your workspace:

  • Requirement 1: Provide at least one anchor (Course Syllabus in Anchor 1 OR Reference Sources in Anchor 2).
  • Requirement 2: Enter your assigned module in Target Coverage Scope (e.g., Rule 130 Section 37-50, Dying Declaration, Fabillar v. Paller).
4 Recitation Mode Presets & 10-Dimension Matrix

Select a primary preset profile, or check and uncheck individual dimension boxes in the Setup matrix — you can customize as you need accordingly to match your professor's specific interrogation style:

§ Codal Mode (Dims 1–3) Isolates statutory definitions, essential elements (numbered lists), and express statutory exceptions/provisos.
⚖️ Case FIR Mode (Dims 5–8) Tests operative facts, legal issues, ratio decidendi, and comparative companion case synthesis (Case X vs. Case Y).
◈ Reviewer Mode (Dims 1, 4, 9, 10) Focuses on doctrinal distinctions, realistic Bar ALAC problem hypotheticals, and procedural remedies.
★ Full Bar Sim (All 10 Dims) Simulates complete bar examinations by cycling across every codal, case, and hypothetical dimension.
